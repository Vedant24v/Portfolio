## 🚀 Deployment

The portfolio is configured for zero-build static hosting on **GitHub Pages**:
1. Commit changes to the `main` branch.
2. In the GitHub repository settings, navigate to **Pages** -> Source: **Deploy from a branch** (`main` / root).
3. The site deploys automatically to `https://vedant24v.github.io/Portfolio/`.
