## 🎨 Visual Identity & Design System

The portfolio features a custom **Luxury Dark Monochrome Aesthetic** paired with physical shader optics and cinematic depth animations:

* **Monochrome Obsidian Palette:** Grounded in `#09090B` (carbon canvas), `#18181B` (zinc surface), `#27272A` (tactile borders), and `#E4E4E7` / `#FFFFFF` (high-contrast typography).
* **ThreeUI Iridescent Glass Shaders:** Integrated using ThreeUI `ShaderButtons` (`iridescent-glass` shader profile) featuring multi-spectral radial caustics (`rgba(55, 142, 254, 0.45)` & `rgba(249, 151, 112, 0.38)`), inset specular reflection borders, interactive light sweep sheen beams, and prismatic gradient lettering.
* **Anime.js v4 Depth Scroll Dynamics:** Inspired by Nominal.so, cards across the Projects and Skills sections arrive from behind into foreground focus via 3D z-axis translation and scale (`scale: [0.88, 1]`, `translateZ: [-60px, 0px]`, `opacity: [0, 1]`).
* **Interactive Starfield Constellation:** Dense 135-particle canvas animation with pointer-proximity vector lines, floating ambient nodes, and periodic twinkling beacons.
* **Micro-Interactions:** Mouse-tracking 3D card tilt physics, fluid modal transitions, accessible keyboard navigation (`Escape`, focus traps), and smooth scroll-spy navigation.

## 🌐 Local Development & Deployment

This portfolio runs as a modern, high-performance static web application requiring zero build step for development:

### 1. Run Locally
```bash
# Clone the repository
git clone https://github.com/Vedant24v/Portfolio.git
cd Portfolio

# Launch with any lightweight HTTP server (e.g. VS Code Live Server, Python, or npx)
npx serve .
# or
python -m http.server 3000
```
Open `http://localhost:3000` in any modern web browser.

### 2. GitHub Pages Deployment
The repository is continuously deployed to **GitHub Pages** directly from the `main` branch. Any commit pushed to `origin main` automatically propagates to the live production site:
